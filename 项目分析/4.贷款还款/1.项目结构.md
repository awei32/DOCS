# 贷款还款-项目结构

## 整体架构

贷款还款模块（hk）与贷款申请（sq）、贷款审批（sp）、合同管理（ht）一致，采用 **API / APP / BUSI** 三层分层：

- **API 层**（`capinfo-gjj-busi-grdk-hk-api`）：对外契约、Feign 客户端、请求/响应/事件 DTO、Topic 常量
- **APP 层**（`capinfo-gjj-busi-grdk-hk-app`）：Spring Boot 启动与运行时配置
- **BUSI 层**（`capinfo-gjj-busi-grdk-hk-busi`）：放款与还款核心业务、领域模型、数据访问、Kafka 订阅与消息分发

模块聚合定义见 [pom.xml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/pom.xml#L18-L21)。

## 各层详细说明

### 1. API 层（capinfo-gjj-busi-grdk-hk-api）

- **职责**：定义跨模块调用契约与消息载荷结构。
- **Feign 入口**（示例）：
  - [HkFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/client/HkFeignClient.java#L27-L28)：`name = capinfo-gjj-busi-grdk-hk-basic-svc`，`path = /api/v1/hk`
  - [HkSshkFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/client/HkSshkFeignClient.java#L22-L25)：`path = /api/v1/hksshk`
  - 另有 `HkSmsFeignClient`、`HkYdchdFeignClient`、`HkHkjhSsFeignClient` 等按场景拆分。
- **Topic 常量**：[HkTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/constant/HkTopicConstant.java) 集中声明个贷还款、放款、冲还贷、转逾期、短信等 Kafka 主题名。

### 2. APP 层（capinfo-gjj-busi-grdk-hk-app）

- **启动类**：[HkApplication](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-app/src/main/java/cn/capinfo/gjj/busi/grdk/hk/app/HkApplication.java#L14-L21)：`@EnableFeignClients(basePackages = "cn.capinfo.gjj")`、`@MapperScan("cn.capinfo.gjj.**.mapper")`、`@EnableDiscoveryClient`。
- **配置要点**（[application.yml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-app/src/main/resources/application.yml#L1-L40)）：
  - 服务名：`capinfo-gjj-busi-grdk-hk-basic-svc`
  - 默认端口：`9204`
  - Kafka、Nacos、Redis、OpenFeign、MyBatis-Plus 等与兄弟模块一致的基础设施

### 3. BUSI 层（capinfo-gjj-busi-grdk-hk-busi）

- **控制层**：
  - [HkController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkController.java#L46-L48)：统一前缀 `/api/v1/hk`，覆盖放款批次、贷款发放、还款总账/明细、扣款数据、日终/年初处理、冲还贷协议、统计报表等大量接口。
  - [HkSshkController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkSshkController.java#L42-L44)：前缀 `/api/v1/hksshk`，实时还款、柜台还款、强制划扣、提前还款登记等。
- **应用服务**：`HkService` / `HkServiceImpl`、`HkSshkService` / `HkSshkServiceImpl` 为业务编排主入口；领域逻辑下沉至 `domain/service`（领域服务接口约 39 个，含实现类）。
- **消息**：
  - 发布：[HkPub](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/service/publish/HkPub.java) 通过 `MessageProducer` 发送领域事件。
  - 订阅：多个 `@KafkaListener` 类将消息交给 `MessageDispatcher`，由 `MessageHandler` 按 `eventType` 路由（见业务层说明文档）。

## 依赖关系

- **模块内**：`hk-app` → `hk-busi`；`hk-busi` → `hk-api` 及 `grdk-core`、结算/归集/个人信息等外部 API 包；`hk-api` 不依赖实现。
- **BUSI 依赖能力**：与 ht/sq 类似，集成 Web、DB、Feign、Kafka、参数中心、分布式 ID 等（详见 [hk-busi/pom.xml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/pom.xml)）。

## 架构特征

- **放款 + 还款一体**：同一模块内既处理放款批次/发放链路，也承载还款总账、计划、扣款与实时还款。
- **Kafka 多 Topic + 统一分发**：个贷专用 Topic 与归集、结算、个人信息等 Topic 并存，消费者侧统一使用 `MessageDispatcher` + `MessageHandler`。
- **双控制器边界**：`/api/v1/hk` 面向全量业务与报表；`/api/v1/hksshk` 聚焦实时还款与柜台场景，Feign 亦拆分对应客户端。

## 典型调用链

```text
其他微服务 / 网关
  -> HkFeignClient / HkSshkFeignClient
  -> HkController / HkSshkController
  -> HkServiceImpl / HkSshkServiceImpl
  -> domain DmService + Mapper（grdk_hk_* / grdk_fk_* 等表）
  -> 可选：HkPub 发 Kafka；结算侧回推由订阅 Handler 处理
```
