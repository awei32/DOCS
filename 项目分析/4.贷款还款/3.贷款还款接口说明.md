# 贷款还款接口说明

## 概述

贷款还款模块对外能力由两类控制器承载，返回值统一为 `R<T>`（部分 `void` 方法为业务侧直接更新）：

- [HkController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkController.java)：`/api/v1/hk`
- [HkSshkController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkSshkController.java)：`/api/v1/hksshk`

跨服务调用契约见 [HkFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/client/HkFeignClient.java)、[HkSshkFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/client/HkSshkFeignClient.java)。

**说明**：`HkController` 方法极多，下列按**业务分组**列出主要路径；未列出的路径以控制器源码为准。

## 11. 与 Feign 的对应关系

- `HkFeignClient` 与 `HkController` 中常用方法路径一致（如 `/jsSshk`、`/pageHkZz` 等），用于其他微服务同步调用。
- `HkSshkFeignClient` 与 `HkSshkController` 路径一致，前缀 `/api/v1/hksshk`。

若需完整方法清单，可在 IDE 中按控制器类 **Structure** 视图展开，或以 OpenAPI（Swagger）注解 `@Operation` 为索引。
