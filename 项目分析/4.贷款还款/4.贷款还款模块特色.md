# 贷款还款模块特色

## 一、模块概述

贷款还款微服务（`capinfo-gjj-busi-grdk-hk`）是个人住房公积金贷款**贷后阶段**的核心服务之一，在工程上与贷款申请、审批、合同等模块通过 Feign 与 Kafka 协同。对外服务名 `capinfo-gjj-busi-grdk-hk-basic-svc`，默认端口 `9204`（见 [application.yml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-app/src/main/resources/application.yml)）。

**能力边界（源码可见）**：

- **放款**：放款批次、放款明细、与资金结算联动的发放/冲账/结果回传。
- **还款账务**：还款总账、明细、还款计划、逾期与结清等。
- **批扣与日终**：扣款数据生成、打包送结算、日终/年初批处理入口（由接口触发）。
- **实时还款**：柜台/渠道实时还款登记，独立 `HkSshkController` 与表 `grdk_hk_sshk`。
- **冲还贷与增值**：冲还贷协议、异地扣款、家庭代际签约、短信等扩展能力。

下文为工程与架构层面的**特色归纳**；接口清单见 [3.贷款还款接口说明.md](./3.贷款还款接口说明.md)，消息对照见 [6.附录-Kafka监听与MessageHandler对照.md](./6.附录-Kafka监听与MessageHandler对照.md)。

## 1. 放款与还款同一微服务承载

与仅做「还款」的狭义模块不同，hk 同时包含：

- **放款侧**：`grdk_fk_pc`、`grdk_fk_pcmx` 批次与明细，接口如 `addFkPc`、`dkff`、`fqfkDbfk`（见 [HkController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkController.java)）。
- **还款侧**：`grdk_hk_zz`、`grdk_hk_mx`、`grdk_hk_hkjh` 等总账/明细/计划。

便于与结算、申请状态在同一 bounded context 内闭环（配合 `HkPub` 发布 `EditSqFkZtEvent` 等）。

---

## 2. Kafka：多 Topic 监听 + 统一 MessageDispatcher

- **个贷统一入口**：[GrdkHkSub](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/service/subscribe/GrdkHkSub.java) 监听 `CAPINFO_GJJ_GRDK_HK_TOPIC`，`groupId = capinfo_gjj_grdk_hk_group`，消息交给 `MessageDispatcher.dispatch`。
- **跨域 Topic**：同一消费者组还订阅资金结算 `CAPINFO_GJJ_ZJJS_YWGL_TOPIC`、归集账户 `CAPINFO_GJJ_GJTQ_GRZH_TOPIC`、记账管理 `CAPINFO_GJJ_GJTQ_JZGL_TOPIC`、个人信息 `CAPINFO_GJJ_GRXX_GRXXGL_TOPIC`（见 `ZjjsYwglSub`、`GjtqGrzhSub`、`GjtqJzglSub`、`GrxxglSub`）。
- **扩展方式**：业务事件类型通过 `MessageHandler.getEventType()` 与 [HkTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/constant/HkTopicConstant.java) 中常量对齐，新增场景主要增 Handler，而非增 Listener。

**注意**：不少 Handler 内 **注释掉** 直连 `@KafkaListener`，保留历史痕迹；以当前「统一 Topic + 分发」为准。

---

## 3. 实时还款与主流程分离（双控制器 + 双 Feign）

- **HTTP 路径拆分**：主业务 `/api/v1/hk` 与实时还款 `/api/v1/hksshk`（[HkSshkController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkSshkController.java)）。
- **契约拆分**：[HkFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/client/HkFeignClient.java) 与 [HkSshkFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/client/HkSshkFeignClient.java)（含独立 `contextId`）避免 Feign Bean 冲突。
- **数据表**：实时还款落库 `grdk_hk_sshk`（[HkSshkDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/domain/dao/HkSshkDO.java)），与总账表分离，便于在途管理与柜台场景。

---

## 4. 日终与批处理通过 API 驱动

- `POST /rzcl` 日终总控内先调用 `HkSshkService.xxhkZdqx()` 自动取消未记账线下还款，再 `hkService.rzclMain`（见 [HkController.rzcl](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkController.java)）。
- 模块内 **无** `@Scheduled`，批处理依赖外部调度触发，便于与参数中心「日切银行列表」等配置联动。

---

## 5. 冲还贷与异地扩展

- **协议与明细**：`grdk_hk_chdmx`、`grdk_hk_chdxy_jl`，接口覆盖签约、解约、扣款顺序审批、列表查询等。
- **异地表**：如 `GRDK_HK_YD_KKSJ_MX`、`GRDK_HK_YD_CHDXY`（见 `HkYdKksjMxDO`、`HkYdChdxyDO`），与本地扣款并存。
- **Topic**：`GRDK_YDCHD_FHJZJG_TOPIC`、`GRDK_YDCHD_PL_KKJG_TOPIC` 等在 `HkTopicConstant` 中定义，对应 Handler 处理异地结果回传（具体业务逻辑以 `*Handler` 实现为准）。

---

## 6. 家庭代际还款

- 提供签约、解约、校验、列表查询等独立接口（`/listJtdjgx`、`/addJtdjgx` 等），表 `grdk_hk_jtdjgx`、`grdk_hk_jtdjgx_jl`。
- 与归集 Topic 监听、代际校验 Handler（如 `GrdkdjgxjcHandler`）配合，实现跨账户代际扣款政策。

---

## 7. 领域模型与持久化表丰富

`domain/dao` 中 `@TableName` 覆盖总账、明细、计划、扣款明细、逾期登记、预约、停还款、免逾期、短信、日结、结清证明、暂收款认领等，体现 **贷后全生命周期** 数据需求。典型表名可参考业务层说明中的 DO 列表。

---

## 8. 参数中心与利率配置深度耦合

- `listXtcsGdll` 在控制器内组合多组 `ParamUtil.parms` / `parm` 调用（`GDSTF`/`GDETF`/`SDSTF`/`SDETF` 等），将公积金/商贷利率段拼装为响应 DTO（见 [HkController.listXtcsGdll](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/controller/HkController.java) 后半段）。
- 日终银行列表 `listRzclYhbh` 使用 `ParamUtil.parms(ConstantsUtils.getHsdwdm(),"GDGL","RQRQ")`。

**特色**：业务规则与「城市代码 + 参数类型」强绑定，换城市依赖参数中心数据而非硬编码。

---

## 9. 小结


| 特色点       | 源码落点                                                 |
| --------- | ---------------------------------------------------- |
| 放款+还款一体   | `FkPc`/`FkPcmx` + `HkZz`/`HkMx` 与统一 `HkServiceImpl`  |
| 消息架构可扩展   | `GrdkHkSub` + 多 `MessageHandler` + `HkTopicConstant` |
| 实时还款隔离    | `HkSshkController` + `grdk_hk_sshk`                  |
| 批处理外置调度   | 仅 `rzcl`/`nclltz` 等 API，无内置 Scheduler                |
| 冲还贷/异地/代际 | 独立表 + 专用 Topic 与 Handler                             |
