# 贷款还款业务层各模块详细说明

## 概述

贷款还款业务层（`capinfo-gjj-busi-grdk-hk-busi`）围绕四条主线组织：

1. **放款主线**：放款批次、放款明细、资金调拨、贷款发放及发放结果/冲账。
2. **还款账务主线**：还款总账（`HkZz`）、还款明细（`HkMx`）、还款计划（`HkHkjh`）、逾期登记、结清证明等。
3. **批扣与结算主线**：日终/扣款数据生成、打包发送结算、批次更新、转逾期记账。
4. **实时还款与柜台主线**：实时还款登记（`grdk_hk_sshk`）、柜台/渠道初始化、强制划扣、提前还款登记。

业务层包结构：`config`、`controller`、`domain`、`service`（含 `impl`、`publish`、`subscribe`）、`validator`。

#### 5.2 MessageHandler（按 eventType 路由）

`subscribe/handler` 下大量 `*Handler` 实现 `MessageHandler`，`getEventType()` 通常返回与 [HkTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-api/src/main/java/cn/capinfo/gjj/busi/grdk/hk/api/constant/HkTopicConstant.java) 中同名的业务主题常量（如 `GRDK_HK_HKYWJZ_TOPIC` 等），由框架将 Kafka 消息分发给对应处理器。

**代表性处理器**（节选）：


| 处理器                                                     | 典型 eventType / 职责                                 |
| ------------------------------------------------------- | ------------------------------------------------- |
| `DkffHandler` / `DkffCwjzHandler` / `DkffCwjzCzHandler` | 贷款发放及财务记账、冲账                                      |
| `HkYwJzHandler`                                         | `GRDK_HK_HKYWJZ_TOPIC` 还款业务记账（实现内可能注释掉具体调用，以源码为准） |
| `HkCwJzHandler`、`HkCzCwJzHandler`、`HkTzCwJzHandler`     | 还款财务记账、冲账、调账                                      |
| `ZyqCwjzHandler`、`ZyqBcsjHandler`                       | 转逾期财务记账、补充数据                                      |
| `ChdClwcHandler`、`ChdKkxxHandler`、`RzclKksjHandler`     | 冲还贷处理完成、扣款信息、日终扣款数据                               |
| `TqhkSpwcHandler`、`GtHkDjGjjSpwcHandler`                | 提前还款/柜台还款审批办结                                     |
| `SmsHandler`                                            | 还款短信等                                             |


**说明**：部分 Handler 内保留注释掉的 `@KafkaListener`，表示历史上直连 Topic 的方式，当前统一走 `GrdkHkSub` 等入口 + `MessageDispatcher`。

### 6. domain 包

- **entity**：领域实体，与 DO/表对应，如 `HkZz`、`HkMx`、`HkHkjh`、`HkSshk`、`FkPc`、`FkPcmx` 等。
- **dao**：`@TableName` 映射物理表，例如 [HkZzDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/domain/dao/HkZzDO.java)、[HkSshkDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/domain/dao/HkSshkDO.java)、[FkPcDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-hk/capinfo-gjj-busi-grdk-hk-busi/src/main/java/cn/capinfo/gjj/busi/grdk/hk/busi/domain/dao/FkPcDO.java)。
- **domain/service**：以 `*DmService` 形式封装单表或聚合持久化（接口约 39 个）。
- **event**：模块内 Spring 事件或消息载荷，如 `TqhkDkqxbgEvent`，供 `HkPub` 发送。

### 7. validator 包

对复杂入参做扩展校验，与 `@Check(validators = ...)` 配合，例如：

- `GthkDjReqDTOValidator`、`HkSshkGjjReqDTOValidator`、`HkSshkTqhkReqDTOValidator`
- `PageHkZzReqDTOValidator`、`HkTzReqDTOValidator`、`HkCzReqDTOValidator`

具体类名以 `busi/validator` 目录为准。

---

### 8. 定时任务

在 `capinfo-gjj-busi-grdk-hk-busi` 内 **未检索到** `@Scheduled` 注解。日终、年初利率调整等通过接口触发（如 `POST /api/v1/hk/rzcl`、`POST /api/v1/hk/nclltz`），由外部调度或人工调用，**不属于 Spring 内置定时任务**。

---

## 小结

- 业务编排集中在 `HkServiceImpl` / `HkSshkServiceImpl`，持久化与规则计算下沉 `domain`。
- 对外 REST 分 `HkController` 与 `HkSshkController` 两类路径，Feign 与之一一对应。
- Kafka 侧以「少数 `KafkaListener` + 大量 `MessageHandler`」扩展事件类型，Topic 名以 `HkTopicConstant` 及兄弟模块常量为准；**Handler 与 eventType 逐项对照**见 [6.附录-Kafka监听与MessageHandler对照.md](./6.附录-Kafka监听与MessageHandler对照.md)。
