# 合同业务流程

## 1. 文档范围

本文基于 `capinfo-gjj-busi-grdk-ht` 源码，说明合同管理模块从“审批通过后生成合同”到“签字生效、担保维护、外联查询、异步自动生合同”的核心流程，覆盖：

- 合同主流程（新增、签字、查询、删除）
- 担保信息维护流程（保证/抵押/组合担保）
- 外联与签章流程（黄河链、担保公司、山东数据局、电子签章）
- 审批消息触发的自动生合同流程

---

## 2. 核心业务主线

合同管理模块围绕 `sqbh`（贷款申请编号）组织数据，并与申请模块（sq）联动：

1. 审批通过后生成合同（`addHt`）
2. 维护担保信息（`saveDbInfo`）
3. 合同签字（`htQz`）
4. 合同查询与变更合同维护（`listHt` + 各变更接口）
5. 外部服务查询与报表签章（FWJK）
6. 审批消息触发自动生合同（Kafka）

主入口见 [HtController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/controller/HtController.java#L27-L258)。

## 3. 状态流转

合同流程主要复用贷款申请状态枚举 [SpztDksqEnum](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-core/src/main/java/cn/capinfo/gjj/busi/grdk/core/enums/SpztDksqEnum.java#L16-L56)：

| 状态码 | 状态名称 | 在合同流程中的含义 |
| --- | --- | --- |
| 60 | 审批通过 | 允许生成合同的前置状态 |
| 65 | 合同生成 | 预留状态（枚举定义） |
| 66 | 合同签字 | 合同生成/签字后回写的核心状态 |

关键约束：

- `addHt` 会校验申请状态必须为“审批通过（60）”，否则拒绝生成合同。参考 [HtServiceImpl.addHt](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/impl/HtServiceImpl.java#L133-L136)。
- 合同生成与签字环节都会回写状态 `66` 到对应合同/贷款记录。参考 [HtServiceImpl.addHt](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/impl/HtServiceImpl.java#L147-L161)、[HtServiceImpl.htQz](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/impl/HtServiceImpl.java#L203-L236)。

## 5. 合同主流程（同步）

### 5.1 步骤1：新增合同

- 接口：`POST /api/v1/ht/addHt`
- 处理：`HtServiceImpl.addHt`
- 关键动作：
  1. 按参数中心规则生成借款合同编号（当前只支持“取 sqbh”模式）
  2. 调用 `sqFeignClient.getDkAndFwBySqbh` 拉取贷款申请与房屋数据
  3. 校验申请状态必须为审批通过（60）
  4. 生成业务受理编号 `ywslbh`
  5. 保存担保合同 `grdk_ht_db`（状态置为 66）
  6. 调用 `sqFeignClient.gxDkxx` 回写申请侧合同编号、签订日、审批状态、合同贷款额

核心代码参考：

- [HtServiceImpl.addHt](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/impl/HtServiceImpl.java#L101-L179)

### 5.2 步骤2：合同签字

- 接口：`POST /api/v1/ht/htQz`
- 处理：`HtServiceImpl.htQz`
- 规则：
  - `HTLX_JKHT`：更新借款合同状态为 `66`，并同步更新申请侧状态
  - `HTLX_DBHT`：更新担保合同状态为 `66`

核心代码参考：

- [HtServiceImpl.htQz](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/impl/HtServiceImpl.java#L202-L241)

### 5.3 步骤3：合同查询/删除

- 合同查询：`listHt` 按合同类型分发到不同领域服务聚合返回
- 合同删除：`delHt` 依次删除清单、借款合同、担保合同、共同借款人合同数据

## 8. 异步自动生合同流程（审批触发）

### 8.1 触发端（sq模块）

审批通过后，sq 模块会根据担保类型决定是否发“自动生合同”消息：

- 消费审批结果：[SqDksqHandler.handle](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sq/busi/service/subscribe/handler/SqDksqHandler.java#L64-L105)
- 规则：
  - 保证担保：发布自动生合同事件
  - 抵押担保：不自动生合同（需担保落实）

### 8.2 消费端（ht模块）

- 统一 topic：`CAPINFO_GJJ_GRDK_HT_TOPIC`，事件类型 `GRDK_HT_ZDSCHT_TOPIC`（见 [HtTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-api/src/main/java/cn/capinfo/gjj/busi/grdk/ht/api/constant/HtTopicConstant.java#L13-L18)）
- 分发入口：[GrdkHtSub](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/subscribe/GrdkHtSub.java#L24-L27)
- 处理器：[HtHandler](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/subscribe/handler/HtHandler.java#L43-L77)
  - 解析 `HtZdscEvtDTO`
  - 补齐签订日期为当天
  - 转换为 `HtAddReqDTO`
  - 调用 `htService.addHt` 完成自动生合同

## 10. 端到端时序（简化）

```text
审批通过（sq）
  -> SqDksqHandler 判断担保类型
  -> (保证担保) 发布自动生合同事件

ht模块消费消息
  -> GrdkHtSub -> HtHandler
  -> 转 HtAddReqDTO
  -> HtServiceImpl.addHt
      -> 拉取sq贷款/房屋数据
      -> 保存grdk_ht_db
      -> 回写sq合同字段与状态(66)

柜面/渠道后续办理
  -> HtDbInfoController.saveDbInfo（担保维护）
  -> HtController.htQz（合同签字）
  -> FwjkReportController.signPdf（签章输出）
```

## 11. 小结

合同模块业务流程具备以下特点：

- 与申请审批强联动：以 `sqbh` 贯穿，合同生成依赖审批通过状态
- 策略化担保处理：保证、抵押、组合担保统一入口、按类型分治
- 同步+异步协同：同步接口提供实时办理，审批消息支持自动生合同
- 可追溯性较好：删除前写入历史表，满足审计留痕
- 外联能力完整：查询、报表、签章在模块内形成闭环
