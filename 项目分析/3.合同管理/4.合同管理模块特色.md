# 合同管理模块特色

## 一、模块概述

合同管理模块（`capinfo-gjj-busi-grdk-ht`）是个人贷款业务系统的核心组成部分，负责管理贷款合同的生成、变更、查询等全生命周期管理。该模块采用微服务架构设计，通过FeignClient与其他模块进行服务间通信。

---

## 二、核心功能特色

### 2.1 合同类型多样化管理

模块支持多种合同类型的管理，满足不同贷款场景需求：

| 合同类型 | 说明 | 对应实体 |
|---------|------|---------|
| 借款合同 | 记录借款人与公积金中心的借款关系 | `HtJk` |
| 担保合同 | 记录贷款担保信息 | `HtDb` |
| 抵押担保 | 房产抵押相关合同信息 | `HtDbDydb` |
| 保证担保 | 第三方保证担保信息 | `HtDbBz` |
| 担保公司协议 | 与担保公司的合作协议 | `HtDbgs` |
| 委托银行协议 | 与受托银行的合作协议 | `HtWtyh` |

### 2.2 合同变更管理

系统支持多种合同变更类型，确保贷款期间信息变更的灵活性和可追溯性：

#### 2.2.1 支持的变更类型

1. **借款人变更** (`HtBgJkr`)
   - 支持主借款人信息变更
   - 支持共同借款人信息变更
   - 记录变更前后的完整信息对比

2. **还款账号变更** (`HtBgHkzh`)
   - 支持还款银行账户变更
   - 自动关联受托银行信息
   - 变更历史完整记录

3. **期限变更** (`HtBgQxbg`)
   - 支持贷款期限延长或缩短
   - 自动重新计算贷款期数、利率
   - 记录变更前后的期限、利率对比

4. **还款方式变更** (`HtBgDkhkfsbg`)
   - 支持等额本息、等额本金等方式切换
   - 变更后重新生成还款计划

### 2.3 策略模式实现担保类型管理

模块采用**策略模式（Strategy Pattern）**实现不同担保类型的灵活管理：

#### 2.3.1 业务背景

在公积金贷款业务中，存在多种担保类型：

| 担保类型 | 代码 | 说明 |
|---------|------|------|
| 抵押 | `01` | 以房产作为抵押物 |
| 保证 | `03` | 第三方提供保证担保 |
| 保证+抵押 | `05` | 组合担保方式 |

不同担保类型对应不同的业务处理逻辑：
- **抵押担保**：需要处理抵押物信息、抵押人信息
- **保证担保**：需要处理保证人信息
- **保证+抵押**：需要同时处理上述两种信息

如果使用传统的 `if-else` 方式，代码会变得臃肿且难以维护。采用策略模式可以优雅地解决这个问题。

##### 2. 策略接口定义

策略接口定义了所有担保类型必须实现的公共行为，并继承 `InitializingBean` 接口实现策略自动注册：

```java
/**
 * 担保策略接口
 * 所有担保类型策略必须实现此接口
 * 
 * 继承 InitializingBean 接口，在 Spring Bean 初始化完成后
 * 自动调用 afterPropertiesSet() 方法完成策略注册
 */
public interface HtDbStrategyFactory extends InitializingBean {

    /**
     * 根据申请编号查询担保信息
     * @param htDbsqBySqbhReqDTO 查询请求参数（包含申请编号、担保类型等）
     * @return 担保信息响应DTO
     */
    HtDbsqResDTO getHtDbsqResDTO(HtDbsqBySqbhReqDTO htDbsqBySqbhReqDTO);

    /**
     * 保存担保信息
     * @param htDbsqReqDTO 担保信息请求DTO
     */
    void saveHtDbsqResDTO(HtDbsqReqDTO htDbsqReqDTO);

    /**
     * 删除担保信息
     * @param htDbsqBySqbhReqDTO 删除请求参数
     */
    void deleteHtDbsqResDTO(HtDbsqDeleteReqDTO htDbsqBySqbhReqDTO);
}
```

##### 3. 策略工厂类

策略工厂负责管理和分发策略实例，使用 `Map` 缓存所有注册的策略：

```java
/**
 * 担保策略工厂
 * 负责策略的注册、存储和获取
 * 
 * 设计要点：
 * 1. 使用静态 Map 存储策略实例，避免重复创建
 * 2. 提供统一的策略获取入口
 * 3. 支持运行时动态扩展新策略
 */
@Service
@Slf4j
public class HtDbFactory {

    /**
     * 策略缓存Map
     * Key: 担保类型代码（如 "01"、"03"、"05"）
     * Value: 对应的策略实现实例
     */
    private static final Map<String, HtDbStrategyFactory> htDbStrategyFactoryMap = new HashMap<>();

    /**
     * 根据担保类型获取对应的策略实例
     * @param dkdblx 贷款担保类型代码
     * @return 策略实现实例
     */
    public static HtDbStrategyFactory getHtDbStrategyFactory(String dkdblx) {
        return htDbStrategyFactoryMap.get(dkdblx);
    }

    /**
     * 注册策略到工厂
     * 由各策略实现类在 afterPropertiesSet() 中调用
     * 
     * @param dkdblx 担保类型代码
     * @param htDbStrategyFactory 策略实现实例
     */
    public static void setHtDbStrategyFactoryMap(String dkdblx, HtDbStrategyFactory htDbStrategyFactory) {
        if (StrUtil.isBlank(dkdblx) || ObjectUtil.isEmpty(htDbStrategyFactory)) {
            return;
        }
        htDbStrategyFactoryMap.put(dkdblx, htDbStrategyFactory);
    }
}
```

##### 4. 具体策略实现 - 保证担保

```java
/**
 * 保证担保策略实现
 * 处理保证担保类型的业务逻辑
 * 
 * 业务特点：
 * 1. 支持自然人担保和机构担保
 * 2. 自然人担保需校验连续缴存月数
 * 3. 自然人担保最多5人，不能重复
 */
@Service
@Slf4j
@Transactional(rollbackFor = Exception.class)
public class HtDbInfoServiceImpl implements HtDbStrategyFactory {

    @Resource
    private HtDbBzService htDbBzService;  // 保证担保领域服务

    /**
     * 查询保证担保信息
     */
    @Override
    public HtDbsqResDTO getHtDbsqResDTO(HtDbsqBySqbhReqDTO htDbsqBySqbhReqDTO) {
        log.info("获取担保信息：{}", JSONUtil.toJsonStr(htDbsqBySqbhReqDTO));
        // 查询保证担保列表
        List<HtDbBzResDTO> htDbBz = htDbBzService.getHtDbBz(htDbsqBySqbhReqDTO);
        // 封装返回结果
        HtDbsqResDTO htDbsqResDTO = new HtDbsqResDTO();
        htDbsqResDTO.setHtDbBzResDTO(htDbBz);
        return htDbsqResDTO;
    }

    /**
     * 保存保证担保信息
     * 采用差集算法处理增删改
     */
    @Override
    public void saveHtDbsqResDTO(HtDbsqReqDTO htDbsqReqDTO) {
        log.info("HtDbInfoServiceImpl-保存担保信息:{}", JSONUtil.toJsonStr(htDbsqReqDTO));
        List<HtDbBzReqDTO> htDbBzReqDTO = htDbsqReqDTO.getHtDbBzReqDTO();
        
        // 查询原有数据
        HtDbsqBySqbhReqDTO htDbsqBySqbhReqDTO = new HtDbsqBySqbhReqDTO();
        htDbsqBySqbhReqDTO.setSqbh(htDbsqReqDTO.getSqbh());
        List<HtDbBzResDTO> htDbBz = htDbBzService.getHtDbBz(htDbsqBySqbhReqDTO);
        
        // 计算差集：找出需要删除和新增的数据
        Set<Long> htDbBzOldIds = htDbBz.stream().map(HtDbBzResDTO::getId).collect(Collectors.toSet());
        Set<Long> htDbBzNewIds = htDbBzReqDTO.stream().map(HtDbBzReqDTO::getId).collect(Collectors.toSet());
        List<Long> intersection = (List<Long>) CollectionUtil.intersection(htDbBzOldIds, htDbBzNewIds);
        
        // 删除旧数据（在旧集合但不在交集中的）
        htDbBzOldIds.removeAll(intersection);
        HtDbsqDeleteReqDTO htDbsqDeleteReqDTO = new HtDbsqDeleteReqDTO();
        htDbsqDeleteReqDTO.setBzIds(Lists.newArrayList(htDbBzOldIds));
        htDbBzService.deleteHtDbBz(htDbsqDeleteReqDTO);
        
        // 新增数据（在新集合但不在交集中的）
        htDbBzNewIds.removeAll(intersection);
        String grdkYwslbh = htDbsqReqDTO.getYwslbh();
        for (HtDbBzReqDTO dbBzReqDTO : htDbBzReqDTO) {
            if (htDbBzNewIds.contains(dbBzReqDTO.getId())) {
                dbBzReqDTO.setId(null);  // 新增数据清除ID
            }
            if (StrUtil.isBlank(dbBzReqDTO.getYwslbh())) {
                dbBzReqDTO.setYwslbh(grdkYwslbh);
            }
            htDbBzService.saveHtDbBz(dbBzReqDTO, htDbsqReqDTO.getBaseInfo());
        }
        log.info("HtDbInfoServiceImpl-保存成功");
    }

    /**
     * 删除保证担保信息
     */
    @Override
    public void deleteHtDbsqResDTO(HtDbsqDeleteReqDTO htDbsqBySqbhReqDTO) {
        log.info("删除担保信息：{}", htDbsqBySqbhReqDTO);
        htDbBzService.deleteHtDbBz(htDbsqBySqbhReqDTO);
        log.info("删除担保信息成功");
    }

    /**
     * 策略自动注册
     * Spring Bean 初始化完成后自动调用
     * 将当前策略注册到工厂，key 为 "03"（保证担保类型代码）
     */
    @Override
    public void afterPropertiesSet() throws Exception {
        HtDbFactory.setHtDbStrategyFactoryMap(DkdblxEnum.BAO_ZHENG.getValue(), this);
    }
}
```

##### 5. 具体策略实现 - 抵押担保

```java
/**
 * 抵押担保策略实现
 * 处理抵押担保类型的业务逻辑
 * 
 * 业务特点：
 * 1. 本房抵押只能有一条记录
 * 2. 抵押权证号、预告登记证号不能重复
 * 3. 需要同时处理抵押物和抵押人信息
 */
@Service
@Slf4j
@Transactional(rollbackFor = Exception.class)
public class HtDyInfoServiceImpl implements HtDbStrategyFactory {

    @Autowired
    private HtDbDydbService htDbDydbService;      // 抵押担保领域服务
    @Autowired
    private HtDbDydbDyrService htDbDydbDyrService; // 抵押人领域服务

    /**
     * 查询抵押担保信息
     * 同时查询抵押物和关联的抵押人信息
     */
    @Override
    public HtDbsqResDTO getHtDbsqResDTO(HtDbsqBySqbhReqDTO htDbsqBySqbhReqDTO) {
        log.info("获取抵押信息:{}，申请编号:{}", DkdblxEnum.DI_YA.getDesc(), JSONUtil.toJsonStr(htDbsqBySqbhReqDTO));
        
        // 查询抵押物信息
        List<HtDbDydbResDTO> htDbDydbResDTOS = htDbDydbService.getHtDbDydb(htDbsqBySqbhReqDTO);
        
        // 查询抵押人信息
        List<HtDbDydbDyrResDTO> htDbDydbDyrs = htDbDydbDyrService.listBySqbh(htDbsqBySqbhReqDTO);
        
        // 组装抵押物与抵押人的关联关系
        for (HtDbDydbResDTO htDbDydbResDTO : htDbDydbResDTOS) {
            Long id = htDbDydbResDTO.getId();
            List<HtDbDydbDyrResDTO> collect = htDbDydbDyrs.stream()
                .filter(item -> item.getDydbId().equals(id))
                .collect(Collectors.toList());
            htDbDydbResDTO.setHtDbDydbDyrDTO(collect);
        }
        
        // 封装返回结果
        HtDbsqResDTO htDbsqResDTO = new HtDbsqResDTO();
        htDbsqResDTO.setHtDbDydbResDTO(htDbDydbResDTOS);
        return htDbsqResDTO;
    }

    /**
     * 保存抵押担保信息
     * 包含业务校验：本房抵押唯一性、权证号唯一性
     */
    @Override
    public void saveHtDbsqResDTO(HtDbsqReqDTO htDbsqReqDTO) {
        log.info("保存抵押信息:{}", htDbsqReqDTO);
        List<HtDbDydbReqDTO> htDbDydbReqDTO = htDbsqReqDTO.getHtDbDydbReqDTO();
        
        // 业务校验：本房抵押只能有一个
        long count = htDbDydbReqDTO.stream()
            .filter(item -> DywlxEnum.BEN_FANG_DI_YA.getValue().equals(item.getDywlx()))
            .count();
        if (count > 1) {
            throw BizException.wrap("本房抵押只能有一个");
        }
        
        // 业务校验：抵押权证号不能重复
        List<String> dyqzhList = htDbDydbReqDTO.stream()
            .map(HtDbDydbReqDTO::getDywqzh)
            .filter(StrUtil::isNotBlank)
            .toList();
        Set<String> dyqzhSet = Sets.newHashSet(dyqzhList);
        
        // 业务校验：预告登记号不能重复
        List<String> ygdjzhList = htDbDydbReqDTO.stream()
            .map(HtDbDydbReqDTO::getYgdjzh)
            .filter(StrUtil::isNotBlank)
            .toList();
        Set<String> ygdjzhSet = Sets.newHashSet(ygdjzhList);
        
        // 综合校验：权证号和预告登记号整体不能重复
        int djhNotNullSize = dyqzhList.size() + ygdjzhList.size();
        dyqzhSet.addAll(ygdjzhSet);
        if (CollectionUtil.isNotEmpty(dyqzhSet) && dyqzhSet.size() != djhNotNullSize) {
            throw BizException.wrap("抵押权证号或预告登记证号不能重复");
        }
        
        // ... 差集处理逻辑（同保证担保）...
        // 保存抵押物和抵押人信息
    }

    /**
     * 策略自动注册
     * 将当前策略注册到工厂，key 为 "01"（抵押担保类型代码）
     */
    @Override
    public void afterPropertiesSet() throws Exception {
        HtDbFactory.setHtDbStrategyFactoryMap(DkdblxEnum.DI_YA.getValue(), this);
    }
}
```

##### 6. 具体策略实现 - 保证+抵押（组合策略）

```java
/**
 * 保证+抵押组合担保策略实现
 * 组合模式：同时调用保证担保和抵押担保策略
 * 
 * 设计亮点：
 * 通过组合已有的策略实现，避免代码重复
 * 体现了策略模式的灵活性和可组合性
 */
@Service
@Slf4j
@Transactional(rollbackFor = Exception.class)
public class HtDbDyInfoServiceImpl implements HtDbStrategyFactory {

    @Resource
    private HtDbInfoServiceImpl htDbInfoService;  // 保证担保策略
    @Resource
    private HtDyInfoServiceImpl htDyInfoService;  // 抵押担保策略

    /**
     * 查询组合担保信息
     * 分别调用保证担保和抵押担保的查询方法，合并结果
     */
    @Override
    public HtDbsqResDTO getHtDbsqResDTO(HtDbsqBySqbhReqDTO htDbsqBySqbhReqDTO) {
        log.info("获取担保+抵押信息：{}", JSONUtil.toJsonStr(htDbsqBySqbhReqDTO));
        
        // 获取保证担保信息
        HtDbsqResDTO htDbsqResDTOByDb = htDbInfoService.getHtDbsqResDTO(htDbsqBySqbhReqDTO);
        
        // 获取抵押担保信息
        HtDbsqResDTO htDbsqResDTOByDy = htDyInfoService.getHtDbsqResDTO(htDbsqBySqbhReqDTO);
        
        // 合并结果
        htDbsqResDTOByDb.setHtDbDydbResDTO(htDbsqResDTOByDy.getHtDbDydbResDTO());
        return htDbsqResDTOByDb;
    }

    /**
     * 保存组合担保信息
     * 分别调用保证担保和抵押担保的保存方法
     */
    @Override
    public void saveHtDbsqResDTO(HtDbsqReqDTO htDbsqReqDTO) {
        log.info("保存担保+抵押信息:{}", htDbsqReqDTO);
        // 保存保证担保信息
        htDbInfoService.saveHtDbsqResDTO(htDbsqReqDTO);
        // 保存抵押担保信息
        htDyInfoService.saveHtDbsqResDTO(htDbsqReqDTO);
        log.info("保存担保+抵押信息成功");
    }

    /**
     * 删除组合担保信息
     * 分别调用保证担保和抵押担保的删除方法
     */
    @Override
    public void deleteHtDbsqResDTO(HtDbsqDeleteReqDTO htDbsqBySqbhReqDTO) {
        log.info("删除担保+抵押信息:{}", htDbsqBySqbhReqDTO);
        htDbInfoService.deleteHtDbsqResDTO(htDbsqBySqbhReqDTO);
        htDyInfoService.deleteHtDbsqResDTO(htDbsqBySqbhReqDTO);
        log.info("删除担保+抵押信息成功");
    }

    /**
     * 策略自动注册
     * 将当前策略注册到工厂，key 为 "05"（保证+抵押类型代码）
     */
    @Override
    public void afterPropertiesSet() throws Exception {
        HtDbFactory.setHtDbStrategyFactoryMap(DkdblxEnum.DIYA_ZHIYEDANBAO.getValue(), this);
    }
```

#### 2.3.6 设计优势

| 优势 | 说明 | 代码体现 |
|------|------|---------|
| **开闭原则** | 新增担保类型无需修改现有代码 | 新增策略类实现接口即可 |
| **单一职责** | 每种担保类型逻辑独立封装 | 每个策略类只处理一种担保类型 |
| **避免条件语句** | 消除大量 if-else 判断 | 控制器中一行代码获取策略 |
| **可组合性** | 策略可以组合使用 | `HtDbDyInfoServiceImpl` 组合两个策略 |
| **自动注册** | 利用 Spring 生命周期自动注册 | `InitializingBean.afterPropertiesSet()` |
| **运行时切换** | 根据参数动态选择策略 | `HtDbFactory.getHtDbStrategyFactory(dkdblx)` |

## 三、技术实现特色

### 3.1 分层架构设计

```
controller/     - 控制层：处理HTTP请求，参数校验
service/        - 业务层：处理业务逻辑
  ├── impl/     - 业务实现
  └── domain/   - 领域服务
    ├── service/ - 领域服务实现
    ├── entity/  - 领域实体
    ├── dao/     - 数据访问对象
    └── factory/ - 工厂类
```

### 3.2 数据一致性保障

- **事务管理**：使用`@Transactional`注解确保业务操作原子性
- **乐观锁机制**：使用`revision`字段实现并发控制
- **异常处理**：统一异常处理机制，确保数据完整性

### 3.3 FeignClient服务调用

模块通过FeignClient与其他微服务进行通信：

| 调用服务 | 用途 |
|---------|------|
| `SqFeignClient` | 获取贷款申请信息、同步合同信息 |
| `JzglFeignClient` | 查询公积金账户缴存信息 |

### 3.4 数据校验机制

- 使用`@Check`注解进行参数校验
- 自定义校验器实现复杂业务规则校验
- 支持担保信息重复性校验、抵押权证号唯一性校验

## 四、关键业务场景

### 4.1 合同生成流程

1. 接收贷款申请编号
2. 校验申请状态（必须为审批通过）
3. 生成借款合同编号
4. 生成业务受理编号
5. 保存担保合同信息
6. 同步更新贷款申请信息
7. 记录合同清单

### 4.2 合同签字流程

1. 接收合同类型和申请编号
2. 根据合同类型更新对应合同状态
3. 同步更新贷款申请状态
4. 记录签字时间

### 4.3 合同变更流程

1. 接收变更申请
2. 校验变更条件
3. 生成业务受理编号
4. 保存变更信息
5. 记录合同清单
6. 触发相关后续业务（如重新生成还款计划）

## 六、扩展性设计

### 6.1 新增担保类型

如需新增担保类型，只需：

1. 创建新的策略实现类，实现`HtDbStrategyFactory`接口
2. 在`afterPropertiesSet()`方法中注册到工厂
3. 无需修改现有业务代码

### 6.2 新增合同变更类型

1. 创建变更实体类继承`BaseEntity`
2. 创建对应的Service接口和实现
3. 在`HtController`中添加接口方法
4. 在`HtService`中实现变更逻辑
