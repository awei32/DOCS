# 合同管理-项目结构

## 整体架构

合同管理模块（ht）采用与贷款申请（sq）、贷款审批（sp）一致的三层分层：

- **API层**（`capinfo-gjj-busi-grdk-ht-api`）：定义对外契约、Feign接口、请求/响应DTO
- **APP层**（`capinfo-gjj-busi-grdk-ht-app`）：Spring Boot 启动与基础设施配置
- **BUSI层**（`capinfo-gjj-busi-grdk-ht-busi`）：合同核心业务实现、领域模型、数据访问、消息处理

模块聚合定义见 [pom.xml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/pom.xml#L17-L21)。

## 各层详细说明

### 1. API层（capinfo-gjj-busi-grdk-ht-api）

- **职责**：定义合同管理跨模块调用契约
- **核心入口**：`HtFeignClient`，统一暴露 `/api/v1/ht` 路由下合同新增、签字、查询、删除、担保查询等接口
- **关键文件**：
  - [HtFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-api/src/main/java/cn/capinfo/gjj/busi/grdk/ht/api/client/HtFeignClient.java#L21-L177)
  - [HtTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-api/src/main/java/cn/capinfo/gjj/busi/grdk/ht/api/constant/HtTopicConstant.java)
- **特点**：
  - DTO按 `req/res/evt` 分层，兼顾同步调用与消息传递
  - 仅包含契约，不承载业务逻辑

### 2. APP层（capinfo-gjj-busi-grdk-ht-app）

- **职责**：合同服务启动与运行时配置承载层
- **启动类**：
  - [HtApplication](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-app/src/main/java/cn/capinfo/gjj/busi/grdk/ht/app/HtApplication.java#L14-L21)
  - 启用了 `@EnableFeignClients`、`@EnableDiscoveryClient`、`@MapperScan`
- **配置要点**（[application.yml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-app/src/main/resources/application.yml#L1-L235)）：
  - 服务名：`capinfo-gjj-busi-grdk-ht-basic-svc`
  - 端口：`9202`
  - 基础设施：Nacos、Kafka、Redis、OpenFeign、MyBatis-Plus
  - 支持多数据库方言映射（MySQL/PostgreSQL/达梦/Kingbase 等）

### 3. BUSI层（capinfo-gjj-busi-grdk-ht-busi）

- **职责**：合同核心业务实现，覆盖合同签订、变更、担保、窗口报表能力
- **控制层**：
  - [HtController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/controller/HtController.java#L27-L258)
  - 统一入口 `/api/v1/ht`，与 API 层契约一一对应
- **服务层**：
  - 接口：[HtService](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/HtService.java)
  - 实现：[HtServiceImpl](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/impl/HtServiceImpl.java)
  - 对外部模块调用：集成 `SqFeignClient` 等能力完成跨模块协同
- **领域层（domain）**：
  - 实体/DAO/领域服务分层组织在 `domain/entity`、`domain/dao`、`domain/service`
  - 典型链路：`HtServiceImpl -> HtDbDmServiceImpl -> HtDbDOMapper`
  - 关键文件：
    - [HtDbDmServiceImpl](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/domain/service/impl/HtDbDmServiceImpl.java)
    - [HtDbDOMapper](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/domain/dao/mapper/HtDbDOMapper.java)
- **消息与扩展能力**：
  - 发布：[HtPub](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/publish/HtPub.java)
  - 订阅：[HtSub](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/src/main/java/cn/capinfo/gjj/busi/grdk/ht/busi/service/subscribe/HtSub.java)
  - 窗口扩展：`fwjk` 包提供模板、PDF、报表相关能力

## 依赖关系

- **模块内依赖**：
  - `ht-app` 依赖 `ht-busi`
  - `ht-busi` 依赖 `ht-api`、`grdk-core`，并联动 `sq-api`、`lp-api`
  - `ht-api` 作为契约层，不依赖业务实现
- **BUSI层基础依赖**（见 [ht-busi/pom.xml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-ht/capinfo-gjj-busi-grdk-ht-busi/pom.xml)）：
  - 基础能力：Web、DB、Feign、Kafka、鉴权、参数校验、分布式ID
  - 业务增强：EasyPOI、iText、Hutool、FastJSON

## 架构特征

- **合同能力集中化**：合同新增、签字、变更、担保查询统一在 ht 模块承载
- **契约驱动协同**：通过 Feign 契约与 sq、lp 等模块协同处理贷款全流程
- **DDD轻量落地**：controller/service/domain/mapper 职责明确
- **消息与同步并存**：同步接口与 Kafka 事件结合，兼顾实时交互与异步处理
- **多数据库适配**：通过 MyBatis `databaseId` 映射支持多种数据库方言

## 典型调用链

```text
外部业务模块
  -> HtFeignClient.addHt/htQz/listHt
  -> HtController
  -> HtServiceImpl
  -> domain service + mapper（合同/担保持久化）
  -> Kafka Publish/Subscribe（异步联动）
```
