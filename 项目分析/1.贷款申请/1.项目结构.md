# 贷款申请-项目结构

## 整体架构
贷款申请模块（sq）采用典型的三层架构设计，遵循微服务分层原则：
- **API层** (`capinfo-gjj-busi-grdk-sq-api`)：定义对外接口和DTO
- **APP层** (`capinfo-gjj-busi-grdk-sq-app`)：应用服务层，负责协调业务逻辑
- **BUSI层** (`capinfo-gjj-busi-grdk-sq-busi`)：核心业务逻辑实现

## 各层详细说明

### 1. API层 (capinfo-gjj-busi-grdk-sq-api)

- **包结构**：`cn.capinfo.gjj.busi.grdk.sq.api`
- **具体组成**：
  - **client包**：包含所有Feign客户端接口定义

    - [ChannelAdapterFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/client/ChannelAdapterFeignClient.java) - 渠道适配接口
    - [GxxxcxFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/client/GxxxcxFeignClient.java) - 公共信息查询接口
    - [SqZxbgFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/client/SqZxbgFeignClient.java) - 征信报告接口

    - **req目录**：请求DTO（109个文件），如 [ChannelSqReqDTO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/dto/req/ChannelSqReqDTO.java)、[SqDkReqDTO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/dto/req/SqDkReqDTO.java) 等
    - **res目录**：响应DTO（72个文件），如 [SqDkResDTO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/dto/res/SqDkResDTO.java)、[SqGtjkrFwDkResDTO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/dto/res/SqGtjkrFwDkResDTO.java) 等
    - **evt目录**：事件DTO（12个文件），用于Kafka消息传递
  - **constant包**：常量定义，如 [SqTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-api/src/main/java/cn/capinfo/gjj/busi/grdk/sq/api/constant/SqTopicConstant.java) 定义Kafka主题常量
- **特点**：
  - 只包含接口定义和数据传输对象，无业务逻辑实现
  - 不包含异常类定义（统一使用父依赖中的 `BizException`）
  - 可被其他模块依赖引用，作为服务间调用的契约
  - 所有接口都使用Spring Cloud OpenFeign注解，支持服务间调用

    - [application-dev-postgre.yml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-app/src/main/resources/application-dev-postgre.yml) - PostgreSQL开发环境  
    - [application-dev-dm.yml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sq/capinfo-gjj-busi-grdk-sq-app/src/main/resources/application-dev-dm.yml) - 达梦数据库开发环境

- **架构特点**：
  - **分层清晰**：严格遵循controller → service → domain的调用链路
  - **接口隔离**：服务层采用接口+实现分离，便于Mock测试和扩展
  - **领域驱动**：通过domain包组织领域模型，体现业务核心概念
  - **模式应用**：广泛使用适配器模式（处理外部系统差异）、工厂模式（对象创建）、观察者模式（事件机制）
  - **企业级特性**：支持事务管理、分布式ID、操作日志、参数校验、消息队列等
  - **可测试性**：各层职责单一，便于单元测试和集成测试

## 依赖关系
- **模块间依赖**：
  - APP层依赖API层和BUSI层
  - BUSI层依赖API层（用于DTO）
  - API层无其他内部依赖

- **外部依赖**：
  - `capinfo-gjj-monitor-expand-starter`：监控扩展包
  - `easypoi-spring-boot-starter`：Excel导出功能（版本4.4.0）

- **父工程**：`capinfo-gjj-busi-grdk` (version: 0.0.1-SNAPSHOT)
- **模块打包**：pom类型（聚合模块）
- **子模块**：
  - capinfo-gjj-busi-grdk-sq-api
  - capinfo-gjj-busi-grdk-sq-app  
  - capinfo-gjj-busi-grdk-sq-busi

## 设计原则
1. **关注点分离**：各层职责明确，避免交叉污染
2. **接口隔离**：API层提供清晰的契约定义
3. **可测试性**：各层可独立单元测试
4. **可维护性**：业务逻辑集中在BUSI层，便于维护和扩展
5. **松耦合**：通过接口依赖而非具体实现

## 典型调用流程
```
外部请求 → APP层Controller → APP层Service → BUSI层Service → 数据库操作
                              ↑
                          事务管理/安全控制/日志
```
