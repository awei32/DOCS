# 贷款审批模块特色设计文档

## 1. 模块概述

贷款审批模块（sp）是贷款业务从“申请提交”走向“审批落地”的关键中枢，负责串联流程发起、待办分发、审批办理、轨迹展示、统计分析与电子档案闭环处理。

**核心定位**：

- 作为贷款业务流程化审批的执行引擎
- 承载“人、岗、组织、代理”多维审批任务分发
- 打通审批结果与电子档案状态的一致性闭环

## 2. 架构设计特色

### 2.1 流程驱动的审批闭环

审批模块以工作流为主线，形成“发起流程 → 查询待办 → 节点审批 → 历史追踪 → 流程图展示”的完整闭环，避免传统状态机在复杂分支下出现的状态漂移问题。

**设计价值**：

- 审批动作围绕流程节点驱动，天然支持串行/并行节点扩展
- 审批历史统一加工后输出，保证前端展示语义一致
- 图形化流程轨迹与文本记录并存，增强审批可解释性

### 2.2 多来源待办聚合模型

待办任务不是单一“个人收件箱”，而是统一聚合以下来源：

- 本人直接待办
- 所属组织候选待办
- 审批代理待办

聚合后再按贷款审批流程类型过滤，并剔除“本人发起本人处理”等无效场景，保证待办列表准确、可执行。

### 2.3 审批代理内建机制

审批代理能力直接内置在模块核心链路中，而非外围功能：

- 支持按代理关系参与待办分发
- 支持代理有效期控制（开始/结束时间窗口）
- 支持个人代理与机构维度代理并行策略

这使模块能适配请假、轮岗、集中审批等组织场景。

## 3. 非CRUD业务能力亮点

### 3.1 审批完成后的电子档案分流

流程结束后自动触发电子档案业务编排，不仅保存审批结果，还同步处理档案状态。

- 审批通过：执行业务办结归档
- 审批拒绝：执行业务作废告知

通过工厂模式按业务类型匹配对应处理器，支持贷款申请、征信变更、抵押变更、借款人变更、还款方式变更等扩展场景。

### 3.2 统计口径与流程变量联动

模块通过流程变量中的业务类型标识（如贷款申请、贷款变更、放款批次）进行统计映射，直接产出：

- 个人待办业务统计
- 部门待办业务统计
- 个人审批量统计

实现“流程任务数据 → 工作台统计指标”的直接转换。

### 3.3 审批轨迹二次加工能力

审批记录输出不是工作流原始数据透传，而是做了业务语义增强：

- “发起人”节点办理人信息修正
- 候选人姓名补齐
- 候选人列表剔除发起人
- 按时间线重排

有效提升审批页面、打印场景、审计追溯场景的可读性。

## 4. 技术栈与中间件

### 4.1 核心技术栈

| 技术领域 | 具体实现 | 主要作用 |
| --- | --- | --- |
| **应用框架** | Spring Boot + Spring MVC | 对外提供审批 REST 接口与应用启动能力 |
| **微服务治理** | Spring Cloud + Nacos + OpenFeign | 服务注册发现、配置管理、跨服务调用 |
| **持久化框架** | MyBatis-Plus | 审批代理等数据实体映射与查询封装 |
| **工作流集成** | 工作流 Feign 客户端 + 工作流扩展 Starter | 流程发起、待办查询、任务审批、轨迹查询 |
| **参数校验** | `@Check` + Jakarta Validation + FluentValidator | 控制层与DTO层双层输入校验 |
| **日志与审计** | Lombok Slf4j + 操作日志注解 | 审批关键动作日志留痕与问题排查 |
| **API 文档** | Swagger/OpenAPI 注解 | 自动生成审批接口说明文档 |
| **工具组件** | Hutool（Bean/JSON/集合/转换） | 数据转换、参数解析与容错处理 |

### 4.2 集成能力特点

- **工作流引擎深度集成**：流程、待办、已办、流程图、审批记录全部通过统一工作流能力接入。
- **电子档案服务集成**：审批结束自动触发办结/作废通知，形成审批与档案的业务闭环。
- **认证组织体系集成**：基于用户与组织信息进行个人待办、机构待办与代理待办聚合。

## 5. 安全与可靠性设计

### 5.1 输入与操作安全

- 请求参数采用注解式校验，降低非法输入对审批流程的污染。
- 关键审批接口配置操作日志，保障审计可追溯。

### 5.2 容错与一致性

- 工作流“创建成功但返回空数据”场景做了防御性兼容。
- 审批动作执行失败统一返回业务失败结果，避免流程状态误判。
- 档案处理按审批结果分支执行，降低“审批通过但档案未闭环”风险。

## 6. 可优化方向

- 部门审批量统计接口已暴露，当前实现尚未返回有效数据，建议补齐并与工作台联调。
- 异常码颗粒度可进一步细化，提升跨模块联调时的定位效率。
- 统计指标可增加时间维度与组织层级钻取能力，增强管理分析价值。

## 7. 总结

贷款审批模块的特色不在于“增删改查”，而在于以工作流为核心，将待办聚合、代理分发、审批办理、统计分析、电子档案归集整合为一体化审批平台能力，具备明显的流程化、规则化、可扩展化特征。
