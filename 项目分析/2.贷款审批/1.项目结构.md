# 贷款审批-项目结构

## 整体架构

贷款审批模块（sp）采用三层分层：

- **API层**（`capinfo-gjj-busi-grdk-sp-api`）：对外契约、Feign接口、审批DTO
- **APP层**（`capinfo-gjj-busi-grdk-sp-app`）：Spring Boot启动与基础设施配置
- **BUSI层**（`capinfo-gjj-busi-grdk-sp-busi`）：审批业务实现、工作流集成、审批代理管理

模块聚合定义见 [pom.xml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/pom.xml#L18-L22)。

## 各层详细说明

### 1. API层（capinfo-gjj-busi-grdk-sp-api）

- **职责**：定义审批服务的跨模块调用契约
- **核心入口**：`SpFeignClient`，统一暴露审批流程、待办、审批代理、统计接口
- **关键文件**：
  - [SpFeignClient](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-api/src/main/java/cn/capinfo/gjj/busi/grdk/sp/api/client/SpFeignClient.java#L20-L151)
  - [SpTopicConstant](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-api/src/main/java/cn/capinfo/gjj/busi/grdk/sp/api/constant/SpTopicConstant.java)
  - [CreateProcessReqDTO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-api/src/main/java/cn/capinfo/gjj/busi/grdk/sp/api/dto/req/CreateProcessReqDTO.java)
  - [CompleteTaskReqDTO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-api/src/main/java/cn/capinfo/gjj/busi/grdk/sp/api/dto/req/CompleteTaskReqDTO.java)
- **特点**：
  - 契约集中在 `/api/v1/sp` 路由
  - DTO按 `req/res/evt` 拆分，适配同步调用与消息传递
  - 无业务实现代码，纯契约层

### 2. APP层（capinfo-gjj-busi-grdk-sp-app）

- **职责**：审批微服务启动和运行时配置承载层
- **启动类**：
  - [SpApplication](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-app/src/main/java/cn/capinfo/gjj/busi/grdk/sp/app/SpApplication.java#L14-L21)
  - 启用了 `@EnableFeignClients`、`@EnableDiscoveryClient`、`@MapperScan`
- **配置要点**（[application.yml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-app/src/main/resources/application.yml#L1-L129)）：
  - 服务名：`capinfo-gjj-busi-grdk-sp-basic-svc`
  - 端口：`9207`
  - 集成：Nacos、Kafka、Redis、OpenFeign、MyBatis-Plus
  - 内置：`tinyid` 与 `lsh` 配置（用于分布式ID与业务流水）
  - 多数据库环境切换：MySQL/PostgreSQL/达梦/Kingbase

### 3. BUSI层（capinfo-gjj-busi-grdk-sp-busi）

- **职责**：审批核心逻辑实现，主要分为“工作流审批能力”和“审批代理能力”
- **控制层**：
  - [SpController](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/controller/SpController.java#L33-L238)
  - 单控制器覆盖流程创建、审批、待办、审批历史、统计、审批代理等接口
- **服务层**：
  - 接口：[SpService](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/service/SpService.java#L16-L129)
  - 实现：[SpServiceImpl](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/service/impl/SpServiceImpl.java#L46-L320)
  - 核心实现点：
    - 通过 `WorkflowFeignClient` 对接工作流引擎
    - 合并“本人待办 + 代理待办”并做业务流程过滤
    - 提供审批统计与审批历史重组
- **领域层（domain）**：
  - 实体：`SpDl`、`SpGc`、`SpWljg`
  - DO映射：
    - [SpDlDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/domain/dao/SpDlDO.java#L18-L19) → `grdk_sp_dl`
    - [SpGcDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/domain/dao/SpGcDO.java#L18-L19) → `grdk_sp_gc`
    - [SpWljgDO](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/domain/dao/SpWljgDO.java#L18-L19) → `grdk_sp_wljg`
  - Mapper位于 `domain/dao/mapper`，领域服务位于 `domain/service`
- **配套层**：
  - Web配置：[SpWebConfiguration](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/config/SpWebConfiguration.java#L11-L13)
  - 校验器：[SpReqDTOValidator](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/src/main/java/cn/capinfo/gjj/busi/grdk/sp/busi/validator/SpReqDTOValidator.java#L14-L24)

## 依赖关系

- **模块内依赖**：
  - `sp-app` 依赖 `sp-busi`
  - `sp-busi` 依赖 `sp-api` 与 `grdk-core`
  - `sp-api` 仅提供契约，不依赖业务实现
- **BUSI层基础依赖**（见 [sp-busi/pom.xml](file:///root/capinfo/gjj/capinfo-gjj-busi-grdk/capinfo-gjj-busi-grdk-sp/capinfo-gjj-busi-grdk-sp-busi/pom.xml#L16-L91)）：
  - 工作流：`capinfo-gjj-workflow-expand-starter`
  - 数据库/Web/Kafka/Auth：对应基础starter
  - 分布式ID与流水：`capinfo-gjj-distributed-id-expand-starter`、`capinfo-gjj-lsh-expand-starter`
  - 跨模块API：`grdk-bg-api`、`grdk-sq-api`、档案服务API

## 架构特征

- **审批能力中台化**：把审批流程创建、任务办理、统计统一在 `sp` 模块
- **流程引擎驱动**：业务审批行为以工作流任务为中心组织
- **代理机制内建**：支持个人代理与机构代理两类待办合并处理
- **DDD轻量落地**：controller/service/domain/mapper分层明确

## 典型调用链

```text
外部业务模块（如sq） 
  -> SpFeignClient.createProcess/completeTask
  -> SpController
  -> SpServiceImpl
  -> WorkflowFeignClient（工作流引擎）
  -> domain service + mapper（审批代理/审批过程数据）
```
